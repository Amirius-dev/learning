=== LEVEL 001: Phonetics Basics ===
⚙️ ПРАВИЛА ЧТЕНИЯ И ПРИМЕРЫ:

- H — немая:
  • Hola -> [Ола] (Привет)
  • Hijo -> [Ихо] (Сын)

- O — всегда чёткая «О» (без «А»):
  • ¿Cómo? -> [Комо?] (Как?)

- J — читается как «Х»:
  • Juan -> [Хуан] (Имя Хуан)
  • Jardín -> [Хардин] (Сад)

- QU — читается как «К» (u — немая):
  • Que -> [Ке] (Что)
  • Queso -> [Кесо] (Сыр)

- Ñ — читается как «НЬ»:
  • España -> [Эспанья] (Испания)
  • Niño -> [Ниньо] (Мальчик)

- LL — читается как «Й»:
  • Me llamo -> [Ме йамо] (Меня зовут)
  • Pollo -> [Пойо] (Курица)

=== LEVEL 002: Intonation, Questions & Accents ===

❓ ВОПРОСЫ И ИНТОНАЦИЯ:

- Порядок слов не меняется, голос идёт вверх 📈.
- На письме в начале обязательно ставится `¿`.
- Пример:
  • Hablas español. -> [Аблас эспаньоль] (Ты говоришь по-испански.)
  • ¿Hablas español? -> [Аблас эспаньоль?] (Ты говоришь по-испански?)

✏️ 3 ПРАВИЛА УДАРЕНИЯ:

1. Окончание на гласную, N или S ➔ предпоследний слог:
   • Casa -> [кА-са] (дом)
   • Hablan -> [А-блан] (они говорят)
2. Окончание на согласную (кроме N, S) ➔ последний слог:
   • Hotel -> [о-тЭль] (отель)
   • Hablar -> [а-блАр] (говорить)
3. Значок `´` (tilde) ➔ перебивает правила:
   • Café -> [ка-фЭ] (кофе)
   • ¿Qué? -> [Ке?] (Что?)

=== LEVEL 003: Greetings & Survival (Full Pack) ===

👋 ПРИВЕТСТВИЯ:
• Hola -> [Ола] (Привет)
• Buenos días -> [Буэнос диас] (Доброе утро)
• Buenas tardes -> [Буэнас тардес] (Добрый день)
• Buenas noches -> [Буэнас ночес] (Добрый вечер / Ночи)
• ¿Qué tal? -> [Ке таль?] (Как дела?)
• ¿Cómo estás? -> [Комо эстас?] (Как ты?)

🤝 ЗНАКОМСТВО И ОТВЕТЫ:
• Mucho gusto -> [Мучо густо] (Приятно познакомиться)
• Encantado / Encantada -> [Энкантадо / а] (Рад / Рада)
• Me llamo... -> [Ме йамо] (Меня зовут...)
• Bien, gracias -> [Бьен, грасиас] (Хорошо, спасибо)

🙏 ВЕЖЛИВОСТЬ И ВЫЖИВАНИЕ:
• Por favor -> [Пор фавор] (Пожалуйста - просьба)
• De nada -> [Де нада] (Пожалуйста - ответ на спасибо)
• Gracias / Muchas gracias -> [Грасиас / Мучас грасиас] (Спасибо / Большое спасибо)
• Perdón / Lo siento -> [Пердон / Ло сьенто] (Извините / Сожалею)
• Sí / No -> [Си / Но] (Да / Нет)
• No sé -> [Но се] (Не знаю)

👋 ПРОЩАНИЕ:
• Adiós -> [Адьос] (Прощай)
• Hasta luego -> [Аста луэго] (До встречи)
• Hasta mañana -> [Аста маньяна] (До завтра)
• Hasta pronto -> [Аста пронто] (До скорого)
• Nos vemos -> [Нос вемос] (Увидимся)

=== LEVEL 004: Numbers, Age, Time & Dates (Full File) ===

⚙️ 1. ЧИСЛА (NUMBERS 1–100):
• 1–10: uno, dos, tres, cuatro, cinco, seis, siete, ocho, nueve, diez
• 11–15 (особая группа): once (11), doce (12), trece (13), catorce (14), quince (15)
• 16–19 (dieci + число): dieciséis (16), diecisiete (17), dieciocho (18), diecinueve (19)
• 20–29 (veinti + число, пишутся СЛИТНО):

- 20: veinte
- 21: veintiuno, 22: veintidós, 23: veintitrés, 24: veinticuatro, 25: veinticinco
- 26: veintiséis, 27: veintisiete, 28: veintiocho, 29: veintinueve
  • Десятки (30–100):
- 30: treinta | 40: cuarenta | 50: cincuenta | 60: sesenta
- 70: setenta | 80: ochenta | 90: noventa | 100: cien
  • Формула для чисел 31–99 (РАЗДЕЛЬНО через "y"):
- [Десяток] + y + [Единица]
- Пример: 34 = treinta y cuatro, 58 = cincuenta y ocho, 99 = noventa y nueve

🎂 2. ВОЗРАСТ (AGE):
• Конструкция: Tener + [число] + años [Тэнго ... аньос]
• Пример: Tengo treinta y cinco años (Мне 35 лет)
• ⛔ БАГ: Никогда не используем глагол "soy" / "estar" для возраста!
• ⚠️ ОРФОГРАФИЯ: Буква Ñ обязательна! (años = года, anos = анальные отверстия)

⏰ 3. ВРЕМЯ (TIME):
• Вопрос: ¿Qué hora es? [Ке ора эс?] — Который час?
• Час (единственное число): Es la una [Эс ла уна] (1:00)
• Остальные часы (множественное число): Son las dos / tres / cuatro...
• Минуты:

- - минуты: y [и] (Son las cuatro y diez = 4:10)
- 15 минут: y cuarto (Son las dos y cuarto = 2:15)
- 30 минут: y media (Son las tres y media = 3:30)
- Без минут (-минуты): menos (Son las cinco menos diez = 4:50 / без десяти пять)

📅 4. ДНИ НЕДЕЛИ И МЕСЯЦЫ (DATES):
• Дни недели (пишутся с МАЛЕНЬКОЙ буквы):

- lunes (ПН), martes (ВТ), miércoles (СР), jueves (ЧТ), viernes (ПТ), sábado (СБ), domingo (ВС)
  • Месяцы (пишутся с МАЛЕНЬКОЙ буквы):
- enero (янв), febrero (фев), marzo (мар), abril (апр), mayo (май), junio (июн)
- julio (июл), agosto (авг), septiembre (сен), octubre (окт), noviembre (ноя), diciembre (дек)
  • Формула даты: Hoy es [день недели], [число] de [месяц]
- Пример: Hoy es viernes, 15 de agosto (Сегодня пятница, 15 августа)
