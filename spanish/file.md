=== LEVEL 001: Phonetics Basics ===
⚙️ ПРАВИЛА ЧТЕНИЯ И ПРИМЕРЫ:

- H — немая:
  • Hola -> [Ола] (Привет)
  • Hijo -> [Ихо] (Сын)

- O — всегда чёткая «О» (без «А»):
  • ¿Cómo? -> [Комо?] (Как?)

- J — читается как «Х»:
  • Juan -> [Хуан] (Имя Хуан)
  • Jardín -> [Хардин] (Сад)

- QU — читается как «К» (u — немая):
  • Que -> [Ке] (Что)
  • Queso -> [Кесо] (Сыр)

- Ñ — читается как «НЬ»:
  • España -> [Эспанья] (Испания)
  • Niño -> [Ниньо] (Мальчик)

- LL — читается как «Й»:
  • Me llamo -> [Ме йамо] (Меня зовут)
  • Pollo -> [Пойо] (Курица)

=== LEVEL 002: Intonation, Questions & Accents ===

❓ ВОПРОСЫ И ИНТОНАЦИЯ:

- Порядок слов не меняется, голос идёт вверх 📈.
- На письме в начале обязательно ставится `¿`.
- Пример:
  • Hablas español. -> [Аблас эспаньоль] (Ты говоришь по-испански.)
  • ¿Hablas español? -> [Аблас эспаньоль?] (Ты говоришь по-испански?)

✏️ 3 ПРАВИЛА УДАРЕНИЯ:

1. Окончание на гласную, N или S ➔ предпоследний слог:
   • Casa -> [кА-са] (дом)
   • Hablan -> [А-блан] (они говорят)
2. Окончание на согласную (кроме N, S) ➔ последний слог:
   • Hotel -> [о-тЭль] (отель)
   • Hablar -> [а-блАр] (говорить)
3. Значок `´` (tilde) ➔ перебивает правила:
   • Café -> [ка-фЭ] (кофе)
   • ¿Qué? -> [Ке?] (Что?)

=== LEVEL 003: Greetings & Survival (Full Pack) ===

👋 ПРИВЕТСТВИЯ:
• Hola -> [Ола] (Привет)
• Buenos días -> [Буэнос диас] (Доброе утро)
• Buenas tardes -> [Буэнас тардес] (Добрый день)
• Buenas noches -> [Буэнас ночес] (Добрый вечер / Ночи)
• ¿Qué tal? -> [Ке таль?] (Как дела?)
• ¿Cómo estás? -> [Комо эстас?] (Как ты?)

🤝 ЗНАКОМСТВО И ОТВЕТЫ:
• Mucho gusto -> [Мучо густо] (Приятно познакомиться)
• Encantado / Encantada -> [Энкантадо / а] (Рад / Рада)
• Me llamo... -> [Ме йамо] (Меня зовут...)
• Bien, gracias -> [Бьен, грасиас] (Хорошо, спасибо)

🙏 ВЕЖЛИВОСТЬ И ВЫЖИВАНИЕ:
• Por favor -> [Пор фавор] (Пожалуйста - просьба)
• De nada -> [Де нада] (Пожалуйста - ответ на спасибо)
• Gracias / Muchas gracias -> [Грасиас / Мучас грасиас] (Спасибо / Большое спасибо)
• Perdón / Lo siento -> [Пердон / Ло сьенто] (Извините / Сожалею)
• Sí / No -> [Си / Но] (Да / Нет)
• No sé -> [Но се] (Не знаю)

👋 ПРОЩАНИЕ:
• Adiós -> [Адьос] (Прощай)
• Hasta luego -> [Аста луэго] (До встречи)
• Hasta mañana -> [Аста маньяна] (До завтра)
• Hasta pronto -> [Аста пронто] (До скорого)
• Nos vemos -> [Нос вемос] (Увидимся)
