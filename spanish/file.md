=== LEVEL 001: Phonetics Basics ===
⚙️ ПРАВИЛА ЧТЕНИЯ И ПРИМЕРЫ:

- H — немая:
  • Hola -> [Ола] (Привет)
  • Hijo -> [Ихо] (Сын)

- O — всегда чёткая «О» (без «А»):
  • ¿Cómo? -> [Комо?] (Как?)

- J — читается как «Х»:
  • Juan -> [Хуан] (Имя Хуан)
  • Jardín -> [Хардин] (Сад)

- QU — читается как «К» (u — немая):
  • Que -> [Ке] (Что)
  • Queso -> [Кесо] (Сыр)

- Ñ — читается как «НЬ»:
  • España -> [Эспанья] (Испания)
  • Niño -> [Ниньо] (Мальчик)

- LL — читается как «Й»:
  • Me llamo -> [Ме йамо] (Меня зовут)
  • Pollo -> [Пойо] (Курица)
